# Hotel-Booking-Revenue-Analysis
MS Excel, SQL

Project Overview

This project analyzes hotel booking data using **Microsoft Excel and SQL Server** to identify revenue trends, booking patterns, customer behavior, room performance, and cancellations.

Objectives

* Analyze total revenue and booking performance.
* Identify the highest revenue-generating hotels and room types.
* Evaluate booking channels and customer segments.
* Analyze booking cancellations and no-shows.
* Provide data-driven business recommendations.

Tools & Technologies

* Microsoft Excel: Data cleaning, PivotTables, KPI analysis, and charts.
* SQL Server: Data aggregation, revenue analysis, and business performance analysis.

Dataset

* Original records: Approximately 20,000
* Cleaned records: 19,982
* Key columns: Hotel, RoomType, CustomerType, Nights, RoomRate, Discount, BookingChannel, BookingStatus, and Revenue.

Key Analysis & Insights

* **Total Revenue:** Approximately ₹525.95 million.
* **Top Revenue-Generating Room:** Suites, contributing approximately ₹195.19 million.
* **Highest Revenue Hotel:** Grand Palace, generating approximately ₹106.74 million.
* **Cancellation Rate:** 14.04%.
* **Average Length of Stay:** Approximately 6 nights.
* **Top Booking Channel by Revenue:** Walk-in, contributing approximately ₹133.21 million.

Business Recommendations

* Promote Suite and Executive room upgrades to increase premium-room revenue.
* Investigate cancellation patterns across hotels and booking channels.
* Develop targeted offers for Individual, Corporate, and Group customers.
* Evaluate booking channel performance using revenue and cancellation metrics.
* Explore demand-based pricing strategies.

Project Workflow

1. Cleaned and validated the raw dataset.
2. Removed duplicate records and corrected invalid values.
3. Calculated revenue using Nights, Room Rate, and Discount.
4. Analyzed booking data using Excel PivotTables and charts.
5. Used SQL Server to analyze and validate business metrics.
6. Developed insights and recommendations based on the results.

Conclusion

This project demonstrates how Excel and SQL Server can be used to transform raw hotel booking data into meaningful business insights and actionable recommendations for improving revenue and booking performance.
